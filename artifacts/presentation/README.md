# Apresentação Cagimadu

Entregáveis:

- `Cagimadu-Apresentacao.pptx`: apresentação editável em 16:9, com 16 slides.
- `Cagimadu-Apresentacao.html`: versão navegável que abre diretamente no navegador.
- `Cagimadu-Apresentacao-standalone.html`: versão HTML independente, com todas as imagens incorporadas.
- `roteiro-apresentacao.md`: guia detalhado de fala e defesa para uma apresentação de 18 a 22 minutos, com perguntas e respostas.
- `screenshots/`: capturas usadas na apresentação; Blocos e Fees foram registrados com dados reais da Ethereum Mainnet.
- `build-presentation.cjs`: fonte programática do PowerPoint.

## Regenerar o arquivo

```bash
cd artifacts/presentation
npm install
npm run build
```

A apresentação usa uma linguagem visual derivada do produto: base clara fria, violeta como assinatura, verde para estado ao vivo e combinação de tipografia sans com mono para dados.

## Usar a versão HTML

Abra `Cagimadu-Apresentacao-standalone.html` com Chrome, Edge ou Firefox. Use as setas para navegar, `F` para tela cheia e `P` para imprimir ou salvar como PDF. Gestos horizontais funcionam em telas sensíveis ao toque.

A tela de Análise de Mercado está identificada no próprio slide como direção visual com dados demonstrativos. As telas de Blocos e Fees foram capturadas com a aplicação integrada à API e à Ethereum Mainnet.
